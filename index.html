Clasificación de la función

Función afín

Esperando

b ≠ 0, c ≠ 0

  • Forma: f(x) = bx + c
  • Recta que no pasa por el origen.
  • Corte con Y: (0, c)
  • Pendiente: —
  • Traslación vertical: c

Función lineal

Esperando

b ≠ 0, c = 0

  • Forma: f(x) = bx
  • Recta que pasa por el origen (0, 0).
  • Pendiente: —

Función constante

Esperando

b = 0, c ≠ 0

  • Forma: f(x) = c
  • Recta horizontal que no coincide con el eje X.

No hay Función

Esperando

b = 0, c = 0

  • Forma: f(x) = 0
  • Es una función constante; su gráfica es el eje X.

Nota: Cuando b = 0 y c = 0 sí hay una función: se llama función nula (f(x) = 0). No es “no hay función”.
