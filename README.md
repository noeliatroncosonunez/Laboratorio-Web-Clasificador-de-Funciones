# Laboratorio-Web-Clasificador-de-Funciones

Página web interactiva desarrollada con HTML, CSS y JavaScript para explorar funciones de la forma f(x) = bx + c mediante coeficientes aleatorios. Clasifica los cuatro casos (función afín, lineal, constante y no hay función), muestra sus propiedades y actualiza la gráfica en un plano cartesiano incrustado de GeoGebra Classic. Incluye selección de archivos .ggb.
