# Laboratorio-Web-Clasificador-de-Funciones
Aplicación web interactiva desarrollada con HTML, CSS y JavaScript para clasificar funciones de primer grado $f(x)=bx+c$ en Lineales ($c=0$) o Afines ($c\neq 0$) mediante coeficientes aleatorios. Incluye despliegue dinámico de propiedades según el tipo de función, enlace a GeoGebra Clásico para su modelación y archivo de construcción
